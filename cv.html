About

Artur is a versatile engineer and project leader with over 10 years of experience building sleek, performant websites, applications, and open-source libraries, public speaking, hosting podcasts and product management. When offline, he can be found playing analog RPGs, brewing drip coffee, and steering canal boats.

uppy.io | github.com/transloadit/uppy | transloadit.com

  • Managed community engagement: resolved GitHub issues, triaged bugs and feature requests, wrote engaging release blog posts (featured on HN/Product Hunt), and scaled user support. Set realistic project goals and release schedules.
  • Conducted regular accessibility audits to ensure features were accessible via keyboard and screen readers.
  • Co-designed and built the new Transloadit.com homepage. Worked on improving the admin interface React app and PHP backend, optimized JS bundle size.
